快速开始

Zomdroid 是一个启动器：它在安卓上运行你自己拥有的 Project Zomboid。应用本身不包含游戏。

  1. 你需要 Linux 版 Project Zomboid，例如在 Steam 或 GOG 上购买的版本。
  2. 获取 Linux 版游戏文件。最快的方式是在电脑上使用 DepotDownloader；没有电脑时， 使用侧边菜单中的从 Steam 下载或从 GOG 下载。如果你已经有 Linux 版文件（例如从电脑上复制过来的），可以跳过这一步。参见获取游戏文件。
  3. 将文件打包为 .zip 压缩包，游戏文件要位于压缩包的顶层。参见打包文件。
  4. 在主界面点击 +，输入名称，选择与你的游戏版本相符的预设，然后选择该 .zip。 Build 41 需要 4 GB 以上内存，Build 42 至少 6 GB，Build 42.12 及更新版本至少 8 GB。
  5. Zomdroid 会自动为你的手机选择渲染器和驱动。如果你改过设置后出了问题，打开实例设置 （齿轮图标）并点击 Suggested preset。
  6. 点击启动按钮 ▶。首次启动时游戏要生成缓存，会比平时慢。

遇到问题？参见报告问题。

获取游戏文件

Zomdroid 需要 Project Zomboid 的 Linux 版本。下面是从 Steam 或 GOG 获取它的方式； 从 Steam 下载的文件之后还需打包为 .zip。已经有 Linux 版文件（例如从电脑上复制过来的）？ 直接跳到打包文件。

1. 在电脑上用 DepotDownloader（最快）

DepotDownloader 可以直接从 Steam 下载游戏的任意版本。在电脑上下载比在手机上快得多。

DepotDownloader 使用指南
  1. 下载 DepotDownloader。 Windows 用户请下载 DepotDownloader-windows-x64.zip。
  2. 解压到任意位置，例如：C:\DepotDownloader
  3. 打开该文件夹，右键 → 在终端 / CMD 中打开
  4. 下载最新公开版本只需要 -app 和 -depot，不需要 manifest 或 beta。将 YOURUSERNAME 和 YOURPASSWORD 替换为你的 Steam 账号信息：

    ./DepotDownloader -app 108600 -depot 108603 -username YOURUSERNAME -password YOURPASSWORD

    如需旧版本或测试版，请加上 -manifest MANIFESTNUMBER，必要时再加 -beta 参数（例如 -beta unstable 或 -beta legacy_42_12）。完整命令可以从 SteamDB 复制：在 "Copy format" 菜单中选择 DepotDownloader，然后点击目标版本旁的复制图标。 可能需要通过 Steam 手机应用验证。
  5. 下载完成后，控制台会显示文件所在的文件夹。按打包文件中的说明打包， 并把 .zip 复制到手机上。

2. 在应用内：从 Steam 下载

无需电脑，但在手机上下载更慢。

  1. 打开侧边菜单，点击从 Steam 下载，选择游戏标签。
  2. 选择 Build 41 或 Build 42，并登录你的 Steam 账号。你的登录信息只发送给 Steam，不会被保存。请在 Steam 应用中批准登录，或输入 Steam 令牌验证码。
  3. 出现提示时，允许访问所有文件：游戏会保存到公共的 Downloads/zomdroid 文件夹。
  4. 等待下载完成。Build 41 约 6–7 GB，Build 42 约 10–11 GB。如果下载中断，再次启动同一版本即可继续。

如果想下载旧版本而不是最新版，在 SteamDB 上找到它，复制它的 DepotDownloader 命令行，把整行粘贴到 manifest 输入框中。

文件会保存在 Downloads/zomdroid/ProjectZomboid_B41_… 或 …_B42_…。里面有三项： projectzomboid 文件夹、.zomdroid_complete… 文件和 projectzomboid.sh。 Zomdroid 暂时不能直接用这个文件夹创建实例：请先把 projectzomboid 里面的内容打包为 .zip，见下文。

3. 从 GOG 获取

GOG 上的 Project Zomboid 没有 DRM，其 Linux 版本是一个安装程序文件 (.sh)。

  1. 打开侧边菜单，点击从 GOG 下载。在 GOG 自己的页面上用 GOG 的邮箱和密码登录：Zomdroid 不会看到你的密码。
  2. 通过关联账号（例如 Google）登录无法在应用内完成。如果你平时是这样登录的，请先设置 GOG 密码：gog.com → Sign in → Password reset。
  3. 点击检查游戏库。Project Zomboid 会显示为一张卡片。
  4. 点击下载。安装程序会保存到公共的 Downloads/zomdroid 文件夹；系统询问时请授予所有文件访问权限。下载期间可以切换到其他应用。如果下载中断，再次点击按钮即可继续。
  5. 下载完成后，按钮会变为创建实例：打开新建实例界面时安装程序已被选中，不需要 .zip。
在电脑上

在 gog.com 的游戏库中下载 Linux 安装程序（.sh 文件）。把它单独打包成一个 .zip，复制到手机，创建实例时选择这个 .zip。之所以需要 .zip，是因为文件管理器不一定能把单独的 .sh 文件交给应用。

4. 将文件打包为 .zip

.zip 压缩包中的游戏文件必须位于顶层，而不是在某个文件夹里： ProjectZomboid64.json、java/、natives/ 等都必须直接位于压缩包内。

在手机上：用文件管理器打开 Downloads/zomdroid/ProjectZomboid_…，再进入其中的 projectzomboid 文件夹。选中该文件夹里面的所有内容，压缩为 ZIP 格式： 不要用 7z 或 rar，也不要从外面压缩整个文件夹。压缩包还需要额外几 GB 的可用空间。

在电脑上

打开游戏文件所在的文件夹（包含 ProjectZomboid64 可执行文件的那个）。在 Linux 上通常是 ~/.local/share/Steam/steamapps/common/ProjectZomboid/projectzomboid。 使用 DepotDownloader 时，就是下载完成后控制台显示的文件夹，例如 Windows 上的 C:\Program Files (x86)\Steam\steamapps\content\app_108600\depot_108603\projectzomboid。 选中所有文件（Ctrl + A，macOS 上为 Command + A），添加到 .zip 压缩包。

把 .zip 放在方便的位置，创建实例时选择它。之后可以删除下载的文件夹：它们占用很多空间。 保留 .zip 不是必须的，但以后重装或创建同一版本的另一个实例时会很方便， 例如一个使用虚拟键盘而不是手柄布局的实例。

Build 41 联机库

Build 41 的联机功能（加入服务器和开服）需要两个额外的库：

  • libRakNet64.so
  • libZNetNoSteam64.so

游戏开发者将它们放在 Linux 版 Build 42.12 的 android 文件夹中。该文件夹里只需要这两个文件。

在实例设置的附加库卡片中安装：

  • 从 Steam：用你的 Steam 账号只下载这两个文件。
  • 从文件：使用你事先准备好的 .zip，两个 .so 文件位于压缩包顶层。创建实例时也可以添加这个 .zip。

没有这些库，Build 41 无法开启服务器功能。Build 42 已自带这两个库。

渲染器与驱动

渲染器负责把游戏的电脑版图形转换为安卓可用的图形。创建实例时，Zomdroid 会为你的手机选择一个； 你可以在实例设置中更改。

GL4ES

Build 41 最稳定的渲染器。在 Build 42 上经常出现图形错误。

NG_GL4ES

适用于任何 GPU 上的 Build 42，无需驱动。在没有骁龙（Adreno）GPU 的手机上，Zomdroid 会选择它。 如果你为了尝试 ZINK 开启过 ANGLE 驱动，使用 NG_GL4ES 时请关闭它：开启 ANGLE 会使帧率大幅下降。

ZINK (ZINK_ZFA, ZINK_OSMESA)

在配备骁龙（Adreno）GPU 的手机上，Build 42 画面效果最好。ZINK 需要 Vulkan 驱动； 在 Adreno 上，Zomdroid 会选择 ZINK_ZFA 并搭配适合你 GPU 的驱动。在其他 GPU 上，ZINK 只能通过 ANGLE 运行且难以设置，因此请使用 NG_GL4ES。

纹理压缩 (ETC2)

NG_GL4ES 和 ZINK 默认开启。它以极小的画质损失压缩大纹理，可以节省大量内存。首次启动需要生成缓存， 耗时更长；缓存可以在实例设置中清除。

ZINK 的 Vulkan 驱动

Freedreno 和 Turnip 都是面向 Adreno GPU 的同一个开源 Mesa 驱动的不同构建，针对不同代的 GPU 做了调整。 如果画面不正常，请尝试其他驱动。

  • Freedreno：Adreno 7xx（骁龙 7 系列）的默认驱动；在部分 6xx 上也可能可用。
  • Freedreno 8xx：Adreno 8xx（骁龙 8 Gen 3 / Gen 4 / Gen 5 / Elite、7 Gen 3）。
  • Freedreno 830/840：Adreno 830/840（骁龙 8 Gen 5 / Elite，例如 Galaxy S25/S26）。
  • TURNIP 740：Adreno 740（骁龙 8 Gen 2）。修复 HyperOS 3 / One UI 更新后的闪烁问题。
  • TURNIP 7xx：Adreno 7xx（骁龙 7 系列）。
  • TURNIP 710：Adreno 710（骁龙 7 Gen 1）。
  • System default：手机自带的 Vulkan 驱动。
  • 自定义驱动：在侧边菜单的导入/导出自定义驱动中导入。

操作

  • 屏幕按键显示在游戏画面上方。在侧边菜单的控制编辑器中修改：添加、移动和调整按钮、摇杆、 触控板和轮盘菜单的大小，并设置每个按键对应的输入。
  • 编辑器中的布局按钮会打开菜单：加载虚拟键鼠布局，或重置为默认手柄布局。 侧边菜单中的导入/导出按键布局可以将布局作为 .zip 文件分享。
  • 支持实体手柄；可在侧边菜单的手柄映射器中重新映射按键。
  • 也支持实体鼠标和键盘。如果想看到游戏自己的光标而不是安卓箭头，请在游戏的显示选项中开启 将光标锁定在窗口。屏幕虚拟鼠标也遵循同样的规则。

快速存档（F10）

在实例设置中开启快速存档（F10）。之后在游戏中按 F10 会完整备份你的世界： 这是崩溃或死亡后可以返回的节点。

  • 存档较大时，备份需要一段时间，游戏可能看起来像卡住了。其实没有：请等待，不要关闭游戏。
  • 每个世界只保留一份备份，新的备份会替换旧的。仅限单人游戏，适用于 Build 41 和 42。
  • 崩溃后，Zomdroid 会提示你返回备份。你也可以在实例的 ⋮ 菜单中选择恢复 F10 备份。
  • F10 按钮已包含在新的操作布局中。如果你使用自己的旧布局，请在控制编辑器中添加： 输入类型 键盘和鼠标，绑定 F10。

模组

  • 从 Steam 下载的模组标签可以按 ID 下载创意工坊模组：ID 是创意工坊链接末尾的数字 （…/filedetails/?id=数字）。无需登录 Steam；多个 ID 可以用空格分隔。每个模组会以 .zip 保存在 Downloads/zomdroid 中。
  • 在侧边菜单的导入模组中安装。智能导入可以在任何 .zip 结构中找到模组文件夹，并自动修复安卓上的路径问题。
  • 侧边菜单中的优化为性能模组 BetterFPS 和 Render Less Zombie 提供了现成的设置。
  • 部分图形模组可能无法正常显示，参见已知问题。

联机与开服

加入服务器。Build 42 可以直接联机。Build 41 需要联机库。 服务器会拒绝以调试模式运行游戏的玩家。

手机可以用两种方式开服：一边玩一边在游戏中开服，或者作为无人游玩的专用服务器。两者都处于实验阶段。

1. 在游戏中开服

在实例设置中开启允许创建服务器，照常启动游戏，然后在游戏中选择建立服务器。

  • 开服使用独立的配置档：开关开启期间，你平时的存档、模组和游戏设置都不会显示，关闭开关后会恢复。
  • 在 Build 42 上，创建服务器时请至少为它分配 2 GB 内存。这是在游戏本身所需内存之外的额外占用， 因此需要一台内存充足的高性能手机。
  • 开服期间请保持游戏打开、屏幕常亮。

2. 专用服务器

手机只运行服务器，全部性能都用于世界运行，玩家用自己的手机加入。打开实例的 ⋮ 菜单， 点击启动服务器。

  • 配置名称：从输入框旁的列表中选择一个配置，它的世界会继续。输入新名称会创建新世界： 输入框下方的一行会提示是哪种情况，并且 Zomdroid 在创建新世界前会先询问你。 如果你手动输入名称，请点击加载配置。
  • 模组、沙盒和出生点最方便在游戏自己的建立服务器界面中设置：开启允许创建服务器后， 在那里创建服务器设置，退出游戏，然后在这里选择该配置。
  • 设置服务器内存（默认 2048 MB）、UDP 端口、最大玩家数、世界自动保存间隔、可选的连接密码和管理员密码。 通过 ID 启用模组，并按加载顺序列出地图，两者都用 ; 分隔。 编辑 PZ 配置文件可以打开完整的服务器设置。
  • 你可以关闭面板并关闭屏幕：服务器会带着通知继续运行。要关闭服务器，请点击保存并停止并等待其完成。
  • 启动服务器前请先退出这台手机上的游戏；服务器运行期间无法启动游戏。 Build 41 需要联机库。

3. 让玩家加入

  • 同一 Wi-Fi：朋友通过开服手机的 Wi-Fi 地址加入。
  • 通过互联网：路由器必须把服务器的 UDP 端口（默认 16261）转发到开服手机。 在路由器上启用 UPnP，或手动设置端口转发。状态栏会显示端口是否已打开以及你的外部地址；点击可查看详情。
  • 使用移动数据时，运营商不允许外部连接进入，因此互联网上的玩家无法直接连接到服务器。 连接到开服手机 Wi-Fi 热点的玩家可以通过它在该网络中的地址加入。其他地方的玩家需要在其他应用中额外设置： 在每部手机上使用共享的虚拟网络，例如 ZeroTier 或 Tailscale。

附加库（Build 42.20+）

游戏的部分库通过 box64 模拟运行。在实例设置的附加库卡片中，你可以改为安装来自游戏 macOS 版的 原生 ARM64 库：它们无需模拟，因此手机在这部分上消耗的内存和 CPU 更少。实验性功能。

  • 从 Steam：如果你拥有游戏即可下载；从文件：使用你之前下载的压缩包。
  • 默认启用所有库。如果出现问题，可以在使用中的库中逐个关闭：关闭的库会使用其常规版本。
  • 同一列表中的 FMOD 是游戏自带的安卓声音库，不是来自 macOS 版。无需下载。

已知问题

下雨时帧率下降

在部分中端手机上，下雨时帧率会明显下降。解决方法：在游戏选项中降低动态水坑设置。

图形模组兼容性

部分图形模组（例如服装、头发或车辆的重制纹理）可能无法正常显示，甚至完全无法使用。

拆解车辆附近界面消失（GL4ES）

使用 GL4ES 时，如果附近有一辆拆下 3 个或更多车轮的车辆，游戏界面可能会消失。 规避方法：不要从同一辆车上拆下超过 2 个车轮。如果界面已经消失，离开该车辆或重新加载存档应可恢复。

报告问题

打开侧边菜单，点击报告错误。它会把日志和你的设置打包为 .zip，并打开一封发给我们的邮件： 选择你的邮件应用（例如 Gmail），填写问题描述，然后点击发送。导出游戏日志只保存游戏本身的日志。
