Mulai cepat

Zomdroid adalah launcher: aplikasi ini menjalankan salinan Project Zomboid milik Anda sendiri di Android. Game-nya sendiri tidak disertakan.

  1. Anda perlu memiliki Project Zomboid di Steam.
  2. Dapatkan file game versi Linux. Cara tercepat adalah DepotDownloader di PC; tanpa PC, gunakan Unduh dari Steam di menu samping. Lihat Mendapatkan file game.
  3. Kemas file ke arsip .zip dengan file game di tingkat teratas. Lihat Mengemas file.
  4. Di layar utama ketuk +, masukkan nama, pilih preset yang sesuai dengan build game Anda, lalu pilih .zip. Build 41 butuh RAM 4 GB atau lebih, Build 42 minimal 6 GB, Build 42.12 ke atas minimal 8 GB.
  5. Zomdroid memilih renderer dan driver untuk ponsel Anda secara otomatis. Jika Anda mengubah pengaturan dan ada yang rusak, buka pengaturan instance (ikon roda gigi) lalu ketuk Suggested preset.
  6. Ketuk tombol mulai ▶. Peluncuran pertama lebih lama karena game membuat cache.

Ada masalah? Lihat Melaporkan masalah.

Mendapatkan file game

Zomdroid membutuhkan versi Linux Project Zomboid, dan Anda harus memiliki game ini di Steam atau GOG. Pilih salah satu cara di bawah; unduhan dari Steam lalu dikemas ke arsip .zip.

1. Di PC dengan DepotDownloader (paling cepat)

DepotDownloader mengunduh build game apa pun langsung dari Steam. Di PC jauh lebih cepat daripada mengunduh di ponsel.

Panduan DepotDownloader
  1. Unduh DepotDownloader. Untuk Windows, ambil DepotDownloader-windows-x64.zip.
  2. Ekstrak di mana saja, misalnya: C:\DepotDownloader
  3. Buka foldernya, klik kanan → Open in Terminal / CMD
  4. Untuk versi publik terbaru Anda hanya perlu -app dan -depot, tanpa manifest atau beta. Ganti YOURUSERNAME dan YOURPASSWORD dengan data akun Steam Anda:

    ./DepotDownloader -app 108600 -depot 108603 -username YOURUSERNAME -password YOURPASSWORD

    Untuk build lama atau beta, tambahkan -manifest MANIFESTNUMBER dan, jika perlu, flag -beta (misalnya -beta unstable atau -beta legacy_42_12). Perintah lengkapnya bisa disalin dari SteamDB: pilih DepotDownloader di menu "Copy format" lalu klik ikon salin di samping build yang diinginkan. Mungkin perlu autentikasi Steam Mobile.
  5. Setelah unduhan selesai, konsol menampilkan folder berisi file. Kemas file tersebut seperti dijelaskan di Mengemas file lalu salin .zip ke ponsel Anda.

2. Di aplikasi: Unduh dari Steam

Tidak perlu PC, tetapi unduhan di ponsel lebih lambat.

  1. Buka menu samping dan ketuk Unduh dari Steam, tab Game.
  2. Pilih Build 41 atau Build 42 dan masuk dengan akun Steam Anda. Login Anda hanya dikirim ke Steam dan tidak disimpan. Setujui login di aplikasi Steam atau masukkan kode Steam Guard.
  3. Saat diminta, izinkan akses ke semua file: game disimpan di folder publik Downloads/zomdroid.
  4. Tunggu. Build 41 sekitar 6–7 GB dan Build 42 sekitar 10–11 GB. Jika unduhan terhenti, jalankan build yang sama lagi dan unduhan akan dilanjutkan.

Untuk mendapatkan versi lama alih-alih yang terbaru, cari di SteamDB, salin baris DepotDownloader-nya dan tempel seluruh baris itu ke kolom manifest.

File akan berada di Downloads/zomdroid/ProjectZomboid_B41_… atau …_B42_…. Di dalamnya ada tiga item: folder projectzomboid, file .zomdroid_complete… dan projectzomboid.sh. Zomdroid belum bisa membuat instance langsung dari folder ini: kemas dulu isi projectzomboid ke .zip, lihat di bawah.

3. Dari GOG

GOG menjual Project Zomboid tanpa DRM, dan versi Linux-nya berupa satu file installer (.sh).

  1. Buka menu samping dan ketuk Unduh dari GOG. Masuk dengan e-mail dan kata sandi GOG di halaman GOG sendiri: Zomdroid tidak pernah melihat kata sandi Anda.
  2. Masuk lewat akun tertaut, misalnya Google, tidak berfungsi di dalam aplikasi. Jika Anda biasanya masuk seperti itu, buat dulu kata sandi GOG: gog.com → Sign in → Password reset.
  3. Ketuk Periksa pustaka. Project Zomboid muncul sebagai kartu.
  4. Ketuk Unduh. Installer disimpan ke folder publik Downloads/zomdroid; izinkan Akses ke semua file saat diminta. Sementara itu Anda bisa beralih ke aplikasi lain. Jika unduhan berhenti, ketuk tombolnya lagi untuk melanjutkan.
  5. Setelah unduhan selesai, tombolnya berubah menjadi Buat instance: layar instance baru terbuka dengan installer yang sudah dipilih, tanpa perlu .zip.
Di PC

Di pustaka Anda di gog.com, unduh installer Linux (file .sh). Kemas file itu sendirian ke dalam arsip .zip, salin ke ponsel, lalu pilih .zip tersebut saat membuat instance. Arsip .zip diperlukan karena pengelola file tidak selalu bisa menyerahkan file .sh langsung ke aplikasi.

4. Mengemas file ke arsip .zip

Arsip .zip harus berisi file game di tingkat teratas, bukan di dalam folder: ProjectZomboid64.json, java/, natives/ dan lainnya harus langsung ada di dalam arsip.

Di ponsel: di pengelola file buka Downloads/zomdroid/ProjectZomboid_…, lalu folder projectzomboid di dalamnya. Pilih semua yang ada di dalam folder itu dan kompres menjadi arsip ZIP: bukan 7z atau rar, dan bukan folder itu sendiri dari luar. Arsip ini butuh beberapa gigabyte ruang kosong lagi.

Di PC

Buka folder berisi file game (yang berisi file eksekusi ProjectZomboid64). Di Linux biasanya ~/.local/share/Steam/steamapps/common/ProjectZomboid/projectzomboid. Dengan DepotDownloader, itu folder yang ditampilkan di konsol saat unduhan selesai, misalnya di Windows C:\Program Files (x86)\Steam\steamapps\content\app_108600\depot_108603\projectzomboid. Pilih semua file (Ctrl + A, atau Command + A di macOS) lalu tambahkan ke arsip .zip.

Simpan .zip di tempat yang mudah dan pilih saat Anda membuat instance. Setelah itu folder unduhan boleh dihapus: ukurannya besar. Menyimpan .zip tidak wajib, tetapi berguna nanti untuk memasang ulang atau membuat instance lain dari versi yang sama, misalnya dengan keyboard virtual alih-alih kontrol gamepad.

Library multiplayer untuk Build 41

Multiplayer di Build 41, baik untuk bergabung ke server maupun hosting, membutuhkan dua library tambahan:

  • libRakNet64.so
  • libZNetNoSteam64.so

Pengembang game menyertakannya di folder android dari Build 42.12 versi Linux. Dari folder itu hanya dua file ini yang diperlukan.

Pasang di pengaturan instance, kartu Library tambahan:

  • Dari Steam hanya mengunduh dua file ini dengan akun Steam Anda.
  • Dari file memakai .zip yang Anda siapkan sebelumnya, dengan kedua file .so di tingkat teratas. .zip ini juga bisa ditambahkan saat membuat instance.

Tanpa library ini, hosting server tidak bisa diaktifkan untuk Build 41. Build 42 sudah menyertakannya.

Renderer dan driver

Renderer menerjemahkan grafis versi desktop game untuk Android. Zomdroid memilihkannya untuk ponsel Anda saat instance dibuat; Anda bisa mengubahnya di pengaturan instance.

GL4ES

Renderer paling stabil untuk Build 41. Di Build 42 sering menampilkan artefak grafis.

NG_GL4ES

Untuk Build 42 di GPU apa pun, tanpa driver. Zomdroid memilihnya di ponsel tanpa GPU Snapdragon (Adreno). Jika Anda mengaktifkan driver ANGLE untuk mencoba ZINK, matikan untuk NG_GL4ES: dengan ANGLE frame rate turun drastis.

ZINK (ZINK_ZFA, ZINK_OSMESA)

Gambar terbaik di Build 42 dengan GPU Snapdragon (Adreno). ZINK butuh driver Vulkan; di Adreno Zomdroid memilih ZINK_ZFA dengan driver yang cocok untuk GPU Anda. Di GPU lain ZINK hanya jalan lewat ANGLE dan sulit diatur, jadi gunakan NG_GL4ES di sana.

Kompresi tekstur (ETC2)

Aktif secara default untuk NG_GL4ES dan ZINK. Mengompresi tekstur besar dengan penurunan kualitas minimal sehingga menghemat banyak memori. Peluncuran pertama membuat cache dan lebih lama; cache bisa dibersihkan di pengaturan instance.

Driver Vulkan untuk ZINK

Freedreno dan Turnip adalah build dari driver Mesa open-source yang sama untuk GPU Adreno, disetel untuk generasi yang berbeda. Jika gambar terlihat salah, coba driver lain.

  • Freedreno: default untuk Adreno 7xx (Snapdragon seri 7); mungkin juga jalan di beberapa 6xx.
  • Freedreno 8xx: Adreno 8xx (Snapdragon 8 Gen 3 / Gen 4 / Gen 5 / Elite, 7 Gen 3).
  • Freedreno 830/840: Adreno 830/840 (Snapdragon 8 Gen 5 / Elite, misalnya Galaxy S25/S26).
  • TURNIP 740: Adreno 740 (Snapdragon 8 Gen 2). Memperbaiki kedipan setelah pembaruan HyperOS 3 / One UI.
  • TURNIP 7xx: Adreno 7xx (Snapdragon seri 7).
  • TURNIP 710: Adreno 710 (Snapdragon 7 Gen 1).
  • System default: driver Vulkan bawaan ponsel.
  • Driver Anda sendiri: impor di menu samping, Impor/Ekspor Driver Kustom.

Kontrol

  • Kontrol di layar tampil di atas game. Ubah di menu samping, Editor kontrol: tambah, pindahkan dan ubah ukuran tombol, stik, touchpad dan menu radial, serta atur apa yang ditekan masing-masing.
  • Tombol Tata letak di editor membuka menu: muat tata letak keyboard dan mouse virtual, atau kembalikan ke tata letak gamepad default. Impor/Ekspor Kontrol di menu samping membagikan tata letak sebagai file .zip.
  • Gamepad fisik berfungsi; atur ulang tombolnya di menu samping, Pengatur gamepad.
  • Mouse dan keyboard fisik juga berfungsi. Agar kursor game terlihat alih-alih panah Android, aktifkan Lock Cursor to Window (mengunci kursor di jendela) di pengaturan tampilan game. Mouse di layar mengikuti aturan yang sama.

Simpan cepat (F10)

Aktifkan Simpan cepat (F10) di pengaturan instance. Menekan F10 di game lalu membuat salinan penuh dunia Anda: titik untuk kembali setelah crash atau kematian.

  • Pada simpanan besar, salinan butuh waktu dan game mungkin terlihat macet. Sebenarnya tidak: tunggu dan jangan tutup.
  • Satu salinan disimpan untuk setiap dunia; salinan baru menggantikan yang lama. Hanya pemain tunggal, Build 41 dan 42.
  • Setelah crash, Zomdroid menawarkan untuk kembali ke salinan. Anda juga bisa memulihkannya dari menu ⋮ instance, Pulihkan salinan F10.
  • Tombol F10 ada di tata letak kontrol yang baru. Dengan tata letak lama milik Anda sendiri, tambahkan di Editor kontrol: jenis input Keyboard & mouse, binding F10.

Mod

  • Unduh dari Steam, tab Mod, mengunduh mod Workshop berdasarkan ID: angka di akhir tautan Workshop (…/filedetails/?id=ANGKA). Tidak perlu login Steam; beberapa ID bisa dipisahkan dengan spasi. Setiap mod disimpan sebagai .zip di Downloads/zomdroid.
  • Pasang di menu samping, Impor Mod. Smart Import menemukan folder mod di struktur .zip apa pun dan memperbaiki masalah path Android secara otomatis.
  • Optimasi di menu samping berisi pengaturan siap pakai untuk mod performa BetterFPS dan Render Less Zombie.
  • Beberapa mod grafis mungkin tidak tampil dengan benar, lihat Masalah yang diketahui.

Multiplayer dan hosting

Bergabung ke server. Build 42 langsung berfungsi. Build 41 membutuhkan library multiplayer. Server menolak pemain yang menjalankan game dalam mode debug.

Ponsel bisa menjadi host dengan dua cara: dari dalam game sambil Anda bermain, atau sebagai server khusus tanpa ada yang bermain di ponsel itu. Keduanya masih eksperimental.

1. Hosting dari dalam game

Aktifkan Izinkan hosting server di pengaturan instance, jalankan game seperti biasa dan pilih HOST di game.

  • Hosting memakai profil terpisah: simpanan, mod, dan pengaturan game Anda yang biasa tersembunyi selama sakelar aktif dan kembali saat Anda mematikannya.
  • Di Build 42, beri server minimal 2 GB memori saat membuatnya. Ini di luar memori yang dibutuhkan game itu sendiri, jadi butuh ponsel kuat dengan RAM besar.
  • Biarkan game tetap terbuka dan layar menyala selama hosting.

2. Server khusus

Ponsel hanya menjalankan server, jadi seluruh tenaganya untuk dunia, dan pemain bergabung dari ponsel mereka sendiri. Buka menu ⋮ instance dan ketuk Jalankan Server.

  • Nama profil: pilih profil dari daftar di samping kolom dan dunianya dilanjutkan. Nama baru membuat dunia baru: baris di bawah kolom memberi tahu yang mana, dan Zomdroid bertanya sebelum membuat dunia baru. Jika Anda mengetik nama secara manual, ketuk Muat profil.
  • Mod, sandbox, dan titik spawn paling mudah diatur di layar HOST milik game: dengan Izinkan hosting server aktif, buat pengaturan server di sana, keluar dari game dan pilih profil itu di sini.
  • Atur memori server (default 2048 MB), port UDP, jumlah pemain maksimal, seberapa sering dunia disimpan, kata sandi koneksi opsional dan kata sandi administrator. Aktifkan mod dengan ID-nya dan urutkan peta sesuai urutan muat, keduanya dipisahkan dengan ;. Edit konfigurasi PZ membuka pengaturan server lengkap.
  • Anda bisa menutup panel dan mematikan layar: server tetap berjalan dengan notifikasi. Untuk mematikannya, ketuk Simpan dan hentikan dan tunggu sampai selesai.
  • Keluar dari game di ponsel ini sebelum menjalankan server; selama server berjalan, game tidak bisa dijalankan. Build 41 membutuhkan library multiplayer.

3. Mengizinkan pemain masuk

  • Wi-Fi yang sama: teman bergabung melalui alamat Wi-Fi ponsel host.
  • Lewat internet: router harus meneruskan port UDP server, default 16261, ke ponsel host. Aktifkan UPnP di router, atau atur penerusan secara manual. Baris status menunjukkan apakah port terbuka dan alamat eksternal Anda; ketuk untuk detail.
  • Dengan data seluler, operator tidak mengizinkan koneksi masuk, jadi pemain dari internet tidak bisa mencapai server secara langsung. Pemain yang terhubung ke hotspot Wi-Fi ponsel host bisa bergabung melalui alamatnya di jaringan itu. Pemain di tempat lain perlu pengaturan tambahan di aplikasi lain: jaringan virtual bersama seperti ZeroTier atau Tailscale di setiap ponsel.

Library tambahan (Build 42.20+)

Sebagian library game berjalan lewat emulasi box64. Di pengaturan instance, kartu Library tambahan, Anda bisa memasang library ARM64 native dari versi macOS game sebagai gantinya: library ini tidak butuh emulasi, jadi ponsel memakai lebih sedikit memori dan CPU. Eksperimental.

  • Dari Steam mengunduhnya jika Anda memiliki game; Dari file memakai arsip yang Anda unduh sebelumnya.
  • Semua library aktif secara default. Jika ada masalah, matikan satu per satu di Pustaka yang digunakan: library yang dimatikan memakai versi biasanya.
  • FMOD di daftar yang sama adalah library suara Android milik game sendiri, bukan dari versi macOS. Tidak perlu mengunduh apa pun.

Masalah yang diketahui

Frame rate turun saat hujan

Di beberapa ponsel kelas menengah, frame rate turun terasa saat hujan. Solusi: turunkan pengaturan Dynamic Puddles (genangan air dinamis) di opsi game.

Kompatibilitas mod grafis

Beberapa mod grafis, seperti retekstur pakaian, rambut, atau kendaraan, mungkin tidak tampil dengan benar atau tidak berfungsi sama sekali.

GUI menghilang di dekat kendaraan yang dibongkar (GL4ES)

Di GL4ES, UI game bisa menghilang jika ada kendaraan di dekatnya dengan 3 roda atau lebih dilepas. Solusi sementara: jangan melepas lebih dari 2 roda dari satu kendaraan. Jika UI sudah menghilang, menjauh dari kendaraan atau memuat ulang simpanan seharusnya memulihkannya.

Melaporkan masalah

Buka menu samping dan ketuk Laporkan bug. Aplikasi mengumpulkan log dan pengaturan Anda ke dalam .zip lalu membuka pesan untuk kami: pilih aplikasi email, misalnya Gmail, tambahkan deskripsi masalah dan ketuk Kirim. Ekspor Log Game hanya menyimpan log game itu sendiri.
